# MAPO Analyzer

Aplicación web para calcular el índice MAPO en salas/unidades de hospitalización a partir de las condiciones de evaluación del método MAPO.

Proyecto completamente independiente de `ocra-video-analyzer`.

## Estado

Primera implementación del flujo analítico: datos OP/NA/NC/PC, factores FS/FA/FC/Famb/FF, cálculo y clasificación.

La metodología y las reglas se mantienen documentadas en `docs/metodologia.md`.
